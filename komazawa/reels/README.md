# 駒澤屋 Reels 自動剪片

1. 員工把影片／照片上傳到雲端「駒澤屋_每日素材」（知道連結可檢視）。
2. 每天 13:37 自動執行：抓新素材 → `inbox/<日期>/` 產生每秒一格的縮圖表與長度資料（原始影片不進 repo）。
3. 排程中的 Claude 看縮圖表挑片段，寫剪輯單到 `edl/<日期>-<主題>.json` 推上來。
4. 推上剪輯單就會自動剪：1080x1920、保留現場聲音、上方品牌標題列、右下 logo → `out/<slug>.mp4` 與封面 `out/<slug>.jpg`。
5. 剪好的影片推到 Eason 的 LINE，確認後再發。

規則：客人的臉一律不能出現。

## 原片備份與失敗不卡關（11/10）
- 新影片進來時自動轉成 1080p 輕量備份存在 `raw/<雲端檔案ID>.mp4`；舊素材每次補備份最多 12 支，雲端已刪的在 manifest 標 `raw_gone`。
- render.py 先用備份、沒有才去雲端抓；兩邊都沒有會明講「這支剪輯單請換片段」。
- 任何一支剪輯單失敗只記錄、繼續剪下一支；成功的照常存檔，最後流程標紅提醒。
